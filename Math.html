বীজগণিতীয় সমীকরণ, মিডল টার্ম ও সমাধান
৩টি সমস্যা
বীজগণিতীয় ভগ্নাংশ সমাধান
দেওয়া আছে,
a/(x − a) + b/(x − b) = (a + b)/(x − a − b) = a/(x − a − b) + b/(x − a − b)

পক্ষান্তর করে পাই:
a/(x − a) − a/(x − a − b) = b/(x − a − b) − b/(x − b)

বা, a [ (x − a − b − x + a) / {(x − a)(x − a − b)} ] = b [ (x − b − x + a + b) / {(x − a − b)(x − b)} ]

বা, a(−b) / [ (x − a)(x − a − b) ] = b(a) / [ (x − a − b)(x − b) ]

উভয়পক্ষকে ab / (x − a − b) দ্বারা ভাগ করে পাই:
বা, −1 / (x − a) = 1 / (x − b)
বা, x − a = −(x − b) = −x + b
বা, x + x = a + b
বা, 2x = a + b
∴ x = (a + b) / 2

উত্তর: নির্ণেয় সমাধান x = (a + b) / 2

দ্বিঘাত সমীকরণ সমাধান
দেওয়া আছে,
2(x² − 9) + 9x = 0
বা, 2x² − 18 + 9x = 0
বা, 2x² + 9x − 18 = 0

মিডল টার্ম ব্রেক (১২ × −৩ = −৩৬ এবং ১২ − ৩ = ৯):
বা, 2x² + 12x − 3x − 18 = 0
বা, 2x(x + 6) − 3(x + 6) = 0
বা, (x + 6)(2x − 3) = 0

হয়, x + 6 = 0 ⇒ x = −6
অথবা, 2x − 3 = 0 ⇒ 2x = 3 ⇒ x = 3/2

∴ নির্ণেয় সমাধান: x = 3/2 অথবা −6

উত্তর: x = 3/2 অথবা −6

সরল সমীকরণ
4(x + 2) = 24
বা, x + 2 = 24 ÷ 4
বা, x + 2 = 6
বা, x = 6 − 2
∴ x = 4

উত্তর: x = 4

০৫
বীজগণিতীয় মান নির্ণয়, উৎপাদক ও প্রমাণ
৪টি সমস্যা
উৎপাদকে বিশ্লেষণ সূত্র
প্রদত্ত রাশি = 144x⁷ − 25x³a⁴
= x³ (144x⁴ − 25a⁴)
= x³ [ (12x²)² − (5a²)² ]   [a² − b² = (a + b)(a − b)]
= x³ (12x² + 5a²)(12x² − 5a²)

উত্তর: x³ (12x² + 5a²)(12x² − 5a²)

ঘনের অনুসিদ্ধান্ত
দেওয়া আছে, x + 1/x = 3
আমরা জানি,
(x − 1/x)² = (x + 1/x)² − 4·x·(1/x)
= (3)² − 4 = 9 − 4 = 5
বা, x − 1/x = √5 [যেহেতু x > 1]

প্রদত্ত রাশি = x³ − 1/x³
= (x − 1/x)³ + 3·x·(1/x)(x − 1/x)
= (√5)³ + 3(√5)
= 5√5 + 3√5 = 8√5

উত্তর: 8√5

বর্গের অনুসিদ্ধান্ত
দেওয়া আছে, x + 1/x = 3

প্রদত্ত রাশি = x² + 1/x²
= (x + 1/x)² − 2·x·(1/x)
= (3)² − 2
= 9 − 2 = 7

উত্তর: 7

বীজগণিতীয় পরিচয় প্রমাণ
দেওয়া আছে, p + q + r = 0
∴ p + q = −r,   q + r = −p,   r + p = −q

বামপক্ষ = (−r)²/(3pq) + (−p)²/(3qr) + (−q)²/(3rp)
= r²/(3pq) + p²/(3qr) + q²/(3rp)
= (r³ + p³ + q³) / (3pqr)
= (p³ + q³ + r³) / (3pqr)

আমরা জানি, p³ + q³ + r³ − 3pqr = (p + q + r)(p² + q² + r² − pq − qr − rp)
যেহেতু p + q + r = 0, তাই p³ + q³ + r³ = 3pqr

∴ বামপক্ষ = 3pqr / 3pqr = 1 = ডানপক্ষ (দেখানো হলো)।
০৬
জ্যামিতি, পরিমিতি ও সাধারণ গণিত প্রশ্নোত্তর
৫টি সমস্যা
পরিমিতি ও ক্ষেত্রফল
ধরি, বাগানের দৈর্ঘ্য = x মিটার এবং প্রস্থ = y মিটার।
১ম শর্তমতে, 2(x + y) = 120 ➔ x + y = 60 ..... (i)
২য় শর্তমতে, 2(x − 3 + 2y) = 150
বা, x − 3 + 2y = 75 ➔ x + 2y = 78 ..... (ii)

সমীকরণ (ii) থেকে (i) বিয়োগ করে পাই:
(x + 2y) − (x + y) = 78 − 60
বা, y = 18 মিটার (প্রস্থ)

এখন, y এর মান (i) এ বসিয়ে পাই:
x + 18 = 60 ➔ x = 42 মিটার (দৈর্ঘ্য)

∴ বাগানের ক্ষেত্রফল = (দৈর্ঘ্য × প্রস্থ) = (42 × 18) = 756 বর্গমিটার
প্রতি বর্গমিটারে ৭ টাকা হারে সারের মোট খরচ = 756 × 7 = ৫,২৯২ টাকা

উত্তর: সার বাবদ মোট ৫,২৯২ টাকা খরচ হবে।

পিথাগোরাসের উপপাদ্য
ধরি, সমকোণী ত্রিভুজটির অপর বাহু = x মিটার।
ক্ষুদ্রতম বাহু = (৩/৪ × x) = 3x/4 মিটার এবং অতিভুজ = ২৫ মিটার।

পিথাগোরাসের সূত্রানুসারে:
x² + (3x/4)² = ২৫²
বা, x² + 9x²/16 = ৬২৫
বা, 25x²/16 = ৬২৫
বা, x² = (৬২৫ × ১৬) / ২৫ = ৪০০
বা, x = √৪০০ = ২০ মিটার (ভূমি/অপর বাহু)

∴ ক্ষুদ্রতম বাহু (উচ্চতা) = (৩ × ২০) / ৪ = ১৫ মিটার
∴ ত্রিভুজটির ক্ষেত্রফল = ½ × ভূমি × উচ্চতা = ½ × ২০ × ১৫ = ১৫০ বর্গমিটার

উত্তর: ত্রিভুজটির ক্ষেত্রফল ১৫০ বর্গমিটার।
